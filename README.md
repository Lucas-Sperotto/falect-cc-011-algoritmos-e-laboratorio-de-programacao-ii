# Algoritmos e Laboratório de Programação II – BCC/UNEMAT/Alto Araguaia

Repositório oficial da disciplina **Algoritmos e Laboratório de Programação II**, ofertada no curso de **Bacharelado em Ciência da Computação da UNEMAT – Campus de Alto Araguaia**.

## Objetivo deste repositório

Este repositório organiza:

- materiais da disciplina;
- roteiros de aula;
- atividades;
- práticas de laboratório;
- projeto integrador;
- orientações de entrega;
- critérios de avaliação;
- políticas de GitHub e uso de IA.

## Estrutura

- `aulas/`: roteiros e materiais por encontro
- `ead/`: vídeos e atividades EAD, quando houver
- `atividades/`: listas, laboratórios e projeto
- `rubricas/`: critérios de avaliação
- `templates/`: modelos de entrega
- `docs/`: PPC, plano e documentos de apoio
- `exemplos/`: códigos e exemplos discutidos em aula
- `src/`: fontes históricos organizados por aulas (98 programas C)
- `docs/REVISAO_FONTES_C.md`: codificação, portabilidade, compilação e verificações

## Ferramentas da disciplina

- VS Code
- Git e GitHub
- Linguagem C (exemplos didáticos em `src/`)
- ChatGPT e Gemini como apoio orientado, quando permitido

## Como estudar nesta disciplina

1. Leia o roteiro da aula.
2. Reproduza os exemplos.
3. Faça a atividade prática.
4. Documente minimamente seu trabalho.
5. Versione corretamente.
6. Respeite as regras de uso de IA da atividade.
7. Tire dúvidas cedo.

## Regras importantes

Leia:

- `POLITICA_GITHUB.md`
- `POLITICA_IA.md`
- `AVALIACAO.md`
- `CRONOGRAMA.md`

## Entregas

As entregas serão informadas nas pastas de atividades e, quando necessário, por `issue`, `pull request` e registro formal no `SIGAA`.

## Observação

O foco desta disciplina não é apenas “fazer funcionar”, mas compreender, justificar, organizar e evoluir soluções computacionais.

## Fontes C e execução

Os programas em `src/` são exemplos didáticos independentes, organizados nas pastas `Fontes_Aula_*`. Compile cada `.c` separadamente. As chamadas históricas `system("PAUSE")` foram **mantidas como comentários**, para evitar executar o comando do Windows. Consulte [orientações de revisão e compilação](docs/REVISAO_FONTES_C.md) antes de executar exemplos antigos.
