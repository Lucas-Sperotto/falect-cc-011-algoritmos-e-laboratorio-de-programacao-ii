# Mapa completo dos fontes C

Este inventário apresenta os nomes existentes em `src/`. Os exemplos são independentes, numerados novamente por conjunto de aulas. Cada fonte possui ID global estável, *link* para a seção da [página da aula](../aulas/README.md) que o explica e, quando existe, para a tarefa do SIGAA. A numeração reinicia por grupo; o [catálogo JSON](auditorias/CATALOGO_FONTES.json) registra também nomes SIGAA, proposta de caminhos, entradas interativas e operações com arquivos. Nenhum fonte foi movido.
